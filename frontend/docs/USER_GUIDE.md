# User guide

## Getting started

1. Open Cuisenio and create an account, or use a demo login (dev).
2. After login you land on **Accueil** (`/home`) — the community feed.
3. Browse recipes, open a detail page, save favorites, leave a rating or comment.

## Discover recipes

- Use the search bar to find recipes by title.
- Filter by category when available.
- Open a card to see ingredients, steps, timing, and difficulty.

## Cook mode helpers

- **Kitchen timer** — start a countdown from the recipe detail page.
- **Shopping list** — add recipe ingredients; tick items as you shop.
- **Recently viewed** — jump back to recipes you opened earlier.

## Meal planner

Open **Planificateur** → assign recipes to days and meal slots → adjust servings.

## Profile

Update your name, theme (light/dark), language preference, and password.

## Install as an app (PWA)

On supported browsers, use the **Install Cuisenio** prompt to add Cuisenio to your home screen. The app shell works offline; previously opened recipe metadata may still be available from local history.
